## To install BepInEx (using the script)
1. download the file [here](https://github.com/NotMonk1/Gorilla-Tag-BepInEx-Installer/releases/tag/maininininin)
2. run the file
3. done!

### NOTE: IF YOU WANT CREDITS IN THE PROGRAM DO THIS
1. Windows + R
2. Type ```cmd``` and hit enter
3. Type ```cd downloads``` (or wherever you have the file)
4. In command prompt type ```bepinexinstaller.bat --credits```
   
   IF YOU RENAMED THE FILE DO ```renamedname.bat --credits```
